Installation
============

energydb can be installed using `pip <https://pypi.org/project/pip/>`_:

.. code-block:: bash

   pip install energydb

or if you are using `uv <https://docs.astral.sh/uv/>`_:

.. code-block:: bash

   uv add energydb

**Install from Cloned Repository:**

To install energydb from a cloned repository for development:

.. code-block:: bash

   git clone https://github.com/rebase-energy/energydb.git
   cd energydb
   pip install -e .

The ``-e`` flag installs the package in editable mode, allowing you to make
changes to the code and see them reflected immediately without reinstalling.

To also install documentation dependencies:

.. code-block:: bash

   pip install -e ".[docs]"


Requirements
------------

energydb requires:

- Python 3.12 or higher
- PostgreSQL database (version 14+) — stores the asset hierarchy, edges, and series catalog
- ClickHouse database — stores all time-series values (via TimeDB)


Dependencies
------------

energydb's runtime stack is intentionally small and pulls TimeDB transitively:

- ``timedb>=0.2.0`` — bitemporal time-series storage on ClickHouse
- ``energydatamodel>=0.0.5`` — Python data model for energy assets
- ``psycopg[binary]>=3.1`` / ``psycopg_pool>=3.1`` — PostgreSQL adapter
- ``sqlalchemy>=2.0`` — declarative ORM (single source of truth for schema)
- ``polars>=1.0`` — primary DataFrame interface for the manifest pipeline
- ``pint>=0.23`` — unit conversion at write/read time


Database Setup
--------------

energydb requires two databases:

- **PostgreSQL** — hosts the ``energydb`` schema (nodes, edges, series catalog, runs)
- **ClickHouse** — hosts TimeDB's ``series_values`` table (all time-series values)

The PostgreSQL schema and the ClickHouse tables are created by a single
``client.create()`` call once the connections are configured.

Set up your database connections using environment variables:

.. code-block:: bash

   # Bash/Zsh
   export TIMEDB_PG_DSN='postgresql://postgres:devpassword@localhost:5433/devdb'
   export TIMEDB_CH_URL='http://default:@localhost:8123/default'

.. code-block:: fish

   # Fish
   set -x TIMEDB_PG_DSN postgresql://postgres:devpassword@localhost:5433/devdb
   set -x TIMEDB_CH_URL http://default:@localhost:8123/default

You can also use a ``.env`` file in your project root:

.. code-block:: text

   TIMEDB_PG_DSN=postgresql://postgres:devpassword@localhost:5433/devdb
   TIMEDB_CH_URL=http://default:@localhost:8123/default

For local development, the simplest path is the same Docker-based setup
distributed with TimeDB — see the
`TimeDB development guide <https://github.com/rebase-energy/timedb/blob/main/DEVELOPMENT.md>`_
for a one-command Postgres + ClickHouse stack.


Verification
------------

After installation, verify that the schema is created correctly:

.. code-block:: python

   import energydb as edb

   client = edb.Client()
   client.create()  # idempotent: creates the energydb schema + CH series_values
   print("ok")

If both databases are reachable, ``client.create()`` returns silently and the
``energydb`` schema and the ``series_values`` ClickHouse table are ready for use.
